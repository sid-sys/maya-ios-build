# Maya — iOS build

Builds the iOS version of **Personal Manifestation: Maya** on GitHub's free
macOS runners.

The app's source code is **not** in this repository. It is private, and is
fetched into the build machine for the length of one job. This repository holds
only the workflow that does that.

- **Build:** Actions → *iOS build* → *Run workflow*.
- A failed build's logs are uploaded encrypted, because this repository's own
  logs are public.
- Issues and pull requests are not read.

Published by Tetradevelopers.
